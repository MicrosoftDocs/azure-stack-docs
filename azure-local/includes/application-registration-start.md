If you plan to deploy a few machines per site, use the Configurator app to register your Azure Local machines with Azure Arc.

## Prerequisites

### Azure Local machine prerequisites

- Download the [Configurator App for Azure Local](https://aka.ms/ConfiguratorAppForHCI) on a client machine that's connected to the same network as the Azure Local machines.

- Note down:

  - The serial number for each machine.
  - Local administrator credentials to sign in to each machine.

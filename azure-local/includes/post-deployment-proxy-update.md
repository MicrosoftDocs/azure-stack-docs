> [!NOTE]
> The registration and environment variable configuration described in this article applies to initial deployment. For an existing Azure Local instance, use `Update-AzureLocalProxy` to make coordinated changes to proxy and bypass settings instead of updating environment variables or appliance settings individually. Existing AKS clusters don't automatically receive these changes. For instructions and limitations, see [Update proxy settings after deployment](../manage/update-proxy-settings.md).

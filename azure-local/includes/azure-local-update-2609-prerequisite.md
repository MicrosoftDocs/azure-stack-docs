> [!IMPORTANT]
> To avoid an issue with older .NET installers, updates to Azure Local versions 2610 and 2611 temporarily require version 2609 as an intermediate update. If you're running a version earlier than 2609, first update to 2609, and then update to 2610 or 2611. If the required .NET runtime is missing after an update, see the [troubleshooting guide](https://github.com/Azure/AzureLocal-Supportability/blob/main/TSG/Update/Troubleshoot-DotNet10-Missing-Runtime.md).

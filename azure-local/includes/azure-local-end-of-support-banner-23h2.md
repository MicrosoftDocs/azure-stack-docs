Azure Stack HCI, version 23H2 OS (OS version 25398.xxxx) reached end of support in April 2026.  

- To keep your Azure Local solution in a supported state, install updates within the N-6 released build window, where N is the latest released build.
- October 2025 (version 11.2510) is the final 23H2 release.
- Support for the 23H2 OS without the Azure Local solution is available until April 2026.

After April 2026:

- You won't receive monthly security and quality updates for 23H2.
- Support requests are only available for patching to a supported release.

Starting with 2602, the Azure portal displays an "End of Support at the end of April" banner for devices running OS version 25398.xxxx (23H2).

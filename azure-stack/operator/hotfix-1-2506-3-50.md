# Azure Stack Hub hotfix 1.2506.3.50

## Summary

- To install this hotfix, you must first update to the [1.2506.2.24 hotfix](hotfix-1-2506-2-24.md). If you are running an earlier hotfix version of 1.2506.*, you must first update to 1.2506.2.24.

## Fixes rolled up from previous hotfix releases

- Added [August 12, 2025 KB5063880 security update for Windows Server 2022](https://support.microsoft.com/topic/august-12-2025-kb5063880-os-build-20348-4052-471ee125-e622-486c-ab3e-5847c8ca4e57).

## Hotfix information

To apply this hotfix, you must have version **1.2506.0.15** or later.

> [!IMPORTANT]
> As outlined in the release notes for the [2506 update](release-notes.md?view=azs-2506&preserve-view=true), make sure that you refer to the update activity checklist on running **Test-AzureStack** (with specified parameters), and resolve any operational issues that are found, including all warnings and failures. Also, review active alerts and resolve any that require action.

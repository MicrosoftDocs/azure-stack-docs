> [!IMPORTANT]
> [Azure App Service on Azure Stack Hub will retire on September 30, 2029](https://aka.ms/appsvconmasretirement).  Customers should plan to migrate affected applications and workloads to Azure App Service in Azure before that date.  New installations of App Service on Azure Stack Hub are no longer supported as of September 30, 2026.  No new product releases, features, or enhancements will be made available. Existing supported deployments can continue to run and upgrade to the latest available release until retirement. After September 30, 2029, Microsoft support for Azure App Service on Azure Stack Hub will end.

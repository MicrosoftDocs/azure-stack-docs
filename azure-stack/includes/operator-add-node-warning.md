> [!WARNING]  
> Azure Stack Hub requires that all servers in the solution have the same configuration. This requirement includes CPU model and cores, memory quantity, NIC and link speeds, and storage devices. Azure Stack Hub doesn't support changing CPU models during hardware replacement or when adding a scale unit node. A change in CPU, such as an upgrade, requires uniform CPUs in each scale unit node and redeployment of Azure Stack Hub.
